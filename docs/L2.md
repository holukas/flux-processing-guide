Expands the quality flags of the EddyPro output into separate test flags.

- **Fluxes:** the same as in L1. Only flags are added, no data are removed.
- **Additional information** from the EddyPro output goes into the flags, e.g. the signal strength of the IRGA.
- **USTAR:** not part of these flags. See [L3.3](L3.3.md).

## Flags

Each test gets its own flag: `0` highest quality, `1` moderate quality, `2` low quality.

| Test | Checks | Applied to |
|---|---|---|
| SSITC | steady state and developed turbulence (Foken and Wichura, 1996; Mauder and Foken, 2006), from the EddyPro output | all fluxes |
| Gas completeness | how complete the 20 Hz gas data are: `0` above 99 %, `1` 97 to 99 %, `2` below 97 % (Sabbatini et al., 2018) | all fluxes |
| Spectral correction factor | out-of-range correction factors: `0` below 2, `1` 2 to 4, `2` 4 and above (Sabbatini et al., 2018) | all fluxes |
| Signal strength | the signal strength of the IRGA, above or below a set value | IRGA fluxes (CO2, H2O) |
| Raw data screening | spikes, amplitude resolution and drop-outs in the 20 Hz data (Vickers and Mahrt, 1997), from the EddyPro output | all fluxes |
| Angle of attack | unrealistic vertical wind from the sonic anemometer | optional, e.g. for periods with a faulty sonic |

- **Signal strength:** for open-path IRGAs, a high value of the automatic gain control (AGC) means a poor signal. For (en)closed-path IRGAs it is usually the other way round.
  - EddyPro does not use the AGC in the flux calculation. It is only used here, in the quality control.
  - The AGC is logged in steps of 6.25 %. The value for the best signal differs between instruments and can change, e.g. from 50 % to 43.75 % after a change inside the instrument. Know the best-signal value of each instrument.
  - The flag rejects records above a set value, e.g. 80 % or 90 %.
- **Empty SSITC flags:** check how many records each flag removes. See [known issues](L1.md#known-issues) in L1.
- **Hard and soft flags:** some tests give only `0` or `2`. See [QCF](QCF.md#test-flags).

## Temporary QCF

- The L2 flags are combined into a first QCF.
- It removes the rejected records before the outlier tests in [L3.2](L3.2.md), so that they run on data that passed L2.
- It is not the final QCF. That one is built in [L3.4](QCF.md#l3.4). See [QCF](QCF.md).
